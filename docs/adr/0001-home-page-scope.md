# Первая фича: статичная Главная страница вместо каталога на `/`

README описывает главную страницу как каталог типов встреч, но первая фича должна сначала рассказать о сервисе и вести гостя к записи. Мы решили отдать `/` статичной Главной странице, перенести каталог на `/catalog` и сделать `/booking` простой заглушкой; существующий маршрут `/book/:id` и полноценное бронирование остаются вне скоупа. Альтернатива — оставить каталог на `/`, а описание сервиса разместить на отдельном пути — отвергнута: она не даёт гостю единого понятного входа в сервис на первом шаге.
